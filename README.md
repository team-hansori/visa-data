# 프로젝트 목적

충청북도 외국인 비자 및 지원사업 자료를 앱에서 검색·계산할 수 있는
구조화 데이터로 변환한다.

# 담당 범위

현재 작업자는 B 담당이다.

- 비자 유형: E-7-4R
- 최신 기준: 2026년 8차 공고
- 변경 이력: 1~7차 공고
- 점수 기준: K-POINT E-7-4 자체 심사표
- 기업 조건: 고용기업 추천양식
- 서식: 신상기술서, 고용계약서 견본, 외국인 변동사유 발생신고서

# 작업 순서

1. 8차 공고의 현재 요건 추출
2. K-POINT 점수 항목 및 구간별 배점 추출
3. 기업 추천 조건 추출
4. 제출서류 메타데이터 정리
5. 8차와 7차 비교
6. 1차까지 역순으로 변경 이력 작성
7. 검수 후 공통 스키마에 반영

# 데이터 규칙

- 모든 값에 출처 문서, 파일 경로, 페이지를 기록한다.
- PDF 원문은 raw_text에 보존한다.
- 복합 조건은 개별 행으로 분리한다.
- 실제 PDF에서 확인되지 않은 값은 추측하지 않는다.
- 값이 없으면 present, not_mentioned, not_checked 등의 상태를 사용한다.
- 최신 차수만 현재 데이터로 입력한다.
- 이전 차수는 변경된 항목만 변경 이력으로 저장한다.
