# documents

E-7-4R 관련 공식 서식의 메타데이터와 서식 검토 초안을 보관한다.

## 파일

- `document_forms.csv`: 서식명, 작성자·제출자·제출처·서명자 등 서식 자체의 메타데이터.
- `_draft_document_forms.csv`: 원문에서 자동 추출한 서식 초안.
- `_draft_document_forms_checklist.txt`: 서식 초안 검토 체크리스트.

서식 메타데이터와 신청자가 실제로 제출해야 하는 증빙서류는 구분한다. 후자는 원문 검수 결과에 따라 공통 `document_requirements`로 매핑할 대상이며, 서식 행을 자동으로 증빙서류 요구사항으로 해석하지 않는다.
